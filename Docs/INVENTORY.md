# Public repository inventory

This edition contains the active VMware PowerCLI toolkit organized under:

- `Inventory/`
- `Storage/`
- `Networking/`
- `Migration/`
- `Security/`
- `Operations/`
- `Modules/`

The private source repository also contained legacy archives, personal notes,
Office documents, book examples, and externally attributed scripts. Those are
intentionally absent from this public edition.

Before running a script, review it for compatibility with your PowerShell,
PowerCLI, vCenter, and ESXi versions. Treat scripts that change infrastructure
as operational examples until they have been tested in your environment.
